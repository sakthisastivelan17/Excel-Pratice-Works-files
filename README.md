# Excel Sales Analysis Using SUMIFS

## Work Overview
This project demonstrates how to use the **SUMIFS function in Microsoft Excel** to analyze sales data and calculate totals based on specific conditions.

The dataset contains sales transactions organized by date, region, product, salesperson, quantity, and amount.

## Dataset Columns
- **Date:** Date of the sales transaction
- **Region:** North, South, East, or West
- **Product:** Laptop, Mouse, or Keyboard
- **Salesperson:** Employee responsible for the sale
- **Quantity:** Number of units sold
- **Amount:** Total sales amount

## Analysis Performed
The project calculates the following:

1. Total sales amount for the North region
2. Total sales amount for the Laptop product
3. Total sales amount generated by Alex

## Excel Formulas

Assuming the dataset is in columns A:F, with headers in row 1 and data in rows 2:13:

### 1. Total Sales for the North Region
```excel
=SUMIFS(F2:F13,B2:B13,"North")
```

**Result:** 88,400

### 2. Total Sales for Laptop
```excel
=SUMIFS(F2:F13,C2:C13,"Laptop")
```

**Result:** 180,000

### 3. Total Sales by Alex
```excel
=SUMIFS(F2:F13,D2:D13,"Alex")
```

**Result:** 71,400

## Key Learnings
- Understanding the SUMIFS function
- Summing values based on specific criteria
- Analyzing sales performance by region, product, and salesperson
- Organizing data and presenting results in Excel

## Tools Used
- Microsoft Excel
- SUMIFS function
- Excel tables and cell formatting

## Conclusion
This project demonstrates how Excel SUMIFS formulas can simplify sales reporting and support data-driven decision-making by summarizing sales across different business categories.

# Excel Inventory Analysis Using SUMIFS

## Work Overview
This project demonstrates the use of the **SUMIFS function in Microsoft Excel** to analyze inventory data and calculate totals using multiple criteria.

The dataset contains part names, categories, departments, quantities, and prices. A summary section presents calculations for selected inventory conditions.

## Dataset Columns
- **Part:** Name or identifier of the part
- **Category:** Fastener, Bearing, Gear, or Shaft
- **Department:** Production or Maintenance
- **Quality:** Quantity available for each part
- **Price:** Price recorded for each part

## Analysis Performed
The project includes the following inventory summaries:

1. Total quantity of Fastener parts
2. Total quantity in the Production department
3. Total quantity of Fastener parts in Maintenance
4. Total price of Bearing-category parts
5. Total quantity of Fastener parts with a quantity greater than 70
6. Total quantity of Production parts with a quantity greater than 40

## Excel Formulas

Assuming the dataset is in columns A:E, with headers in row 1 and data in rows 2:9:

### 1. Total Quantity of Fastener Parts
```excel
=SUMIFS(D2:D9,B2:B9,"Fastener")
```

**Result:** 360

### 2. Total Quantity in Production
```excel
=SUMIFS(D2:D9,C2:C9,"Production")
```

**Result:** 320

### 3. Total Quantity of Fastener Parts in Maintenance
```excel
=SUMIFS(D2:D9,B2:B9,"Fastener",C2:C9,"Maintenance")
```

**Result:** 160

### 4. Total Price of Bearing Parts
```excel
=SUMIFS(E2:E9,B2:B9,"Bearing")
```

**Result:** 330

### 5. Total Quantity of Fastener Parts Greater Than 70
```excel
=SUMIFS(D2:D9,B2:B9,"Fastener",D2:D9,">70")
```

**Result:** 300

### 6. Total Quantity of Production Parts Greater Than 40
```excel
=SUMIFS(D2:D9,C2:C9,"Production",D2:D9,">40")
```

**Result:** 250

## Key Learnings
- Applying SUMIFS with one or multiple criteria
- Using text conditions to filter inventory categories and departments
- Applying numerical criteria such as greater than 40 or 70
- Summarizing inventory data for reporting and analysis

## Tools Used
- Microsoft Excel
- SUMIFS function
- Excel tables, filters, and conditional criteria

## Conclusion
This project illustrates how Excel SUMIFS formulas can support inventory reporting by calculating quantities and prices based on part categories, departments, and numerical conditions.
